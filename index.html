Aussie Rules

Master the spelling tricks for Australian workplaces.

🇦🇺 -ise (Not -ize)

Australian English uses -ise for most verbs. American English uses -ize.

organise organize
realise realize
apologise apologize
Memory trick: Think "S" for "Straya".

🇦🇺 -our (Not -or)

Most nouns ending in an "uh" sound use -our in Australia.

colour color
behaviour behavior
favour favor

🇦🇺 -re (Not -er)

Centre, theatre, metre. In Australia, we put the "r" before the "e" in these words.

centre center
theatre theater
metre meter

🇦🇺 -ce vs -se

In Australian English, the noun ends in -ce, but the verb ends in -se.

licence (noun) vs license (verb)
practice (noun) vs practise (verb)
Example: "I need a driver's licence to license this vehicle."

🇦🇺 -ogue (Not -og)

Australian English keeps the French "ue" at the end of these words.

catalogue catalog
dialogue dialog
analogue analog

🇦🇺 Double L

When adding a suffix like -ing or -ed, we double the L in Australia.

travelling traveling
cancelled canceled
modelling modeling
